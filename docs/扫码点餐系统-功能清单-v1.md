# 扫码点餐系统｜最小版本【局域网打印版】功能清单（MD）

> 
> 版本说明：最小可用版｜局域网内网打印
> 约束：仅堂食扫码点餐、线下前台结算、不含外卖、不含线上支付、不含独立服务员端、不含交互式后厨平板；去掉飞鹅 / 芯烨云第三方云打印，使用局域网 ESC/POS TCP 9100 打印；后厨依靠内网 WiFi / 网口热敏打印机出纸质小票流转，上菜靠小票 + 口头喊单，无系统划菜、上菜通知。
> 前端架构约定：
> 
> 
> 1. `admin`：商家 Web 管理后台 + 前台收银 H5 **合并为同一个前端项目**，通过路由 + 后端角色权限隔离；角色分为【管理员】、【收银员】
> 2. `web`：顾客扫码点餐 H5，独立前端项目
> 3. `api`：统一后端服务
> 
> 
> ⚠️ 局域网打印前提：后端服务部署在店内常开内网主机；打印机配置静态内网 IP，端口 9100；后端和打印机同网段；打印使用 Socket 直连下发 ESC/POS 指令，不依赖厂商云。

## 一、顾客 H5 端（独立前端项目，扫码点餐）

入口：桌台二维码，二维码绑定 `tableId` 桌号

- 扫码自动带入桌号，桌号由二维码锁定，顾客端不可手动修改（防止跨桌点单、传错桌号导致上错菜）；贴错码、换桌由服务员引导重新扫码或收银端调整
- 门店基础提示文字展示
- 菜品分类展示（分类由后台配置、支持排序）
- 菜品卡片：名称、图片、售价、规格组、加料选项、售罄置灰
- 菜品搜索：按名称/分类关键词跨分类检索（独立搜索页）
- 规格选择：大小份、辣度、冰度等（后台配置，选项支持差价，按所选规格计价）
- 加料选择：可配置加价加料项，支持限选数量（限 N 份 / 不限）
- 购物车：增减数量、删除菜品、修改规格
- 整单备注输入框（少辣、不要葱等）
- 订单预览：菜品明细、小计金额
- 提交订单（**无在线支付按钮**）
- 提交成功弹窗：展示订单号，提示前往前台结账
- 本桌订单：查看本次就餐会话的订单列表与明细（同桌共享；最后一批订单结清/取消后自动换新会话，上一桌订单不再展示）
- 校验：售罄菜品不可勾选；购物车为空禁止提交订单

> 
> 不包含：会员线上充值、线上优惠券核销、催单、顾客自主取消订单（最小版取消统一收银处理）

## 二、admin 合并前端项目（商家后台 + 收银 H5）

> 
> 共用一套登录、请求封装、公共组件；路由守卫控制页面访问权限；**最终权限以后端接口鉴权为准**
> 角色：
> 
> 
> - 管理员：
> - 收银员：

### 2.1 公共模块（登录、共享组件）

- 用户账号密码登录，返回 Token 鉴权
- 登录页：区分角色，登录后跳转对应首页
- 公共组件：订单卡片、打印预览、时间筛选器、退菜弹窗
- 退出登录、修改密码
- 全局请求拦截，统一错误提示

### 2.2 收银模块（收银员、管理员均可访问）

- 桌台概览列表：区分空闲 / 待结算（有未结订单）
- 订单检索：按桌号、订单号查询订单
- 订单详情查看：菜品、规格、加料、备注、下单时间、合计金额
- 订单改单：新增菜品、修改数量、修改规格、修改备注
- 单品退菜：选择菜品退菜，可选填写退菜原因
- 整单取消：清空当前桌台未结算订单
- 金额自动汇总，抹零功能（后台开关控制）
- 结算方式选择：现金 / 前台微信静态码 / 前台支付宝静态码 / 其他

> 
> 重点：系统不校验支付结果，收银员线下确认收款后手动点击结算

- 确认结算：订单标记【已结清】，自动触发局域网打印顾客结账单
- 挂单：订单暂存，不结算，保留在桌台列表
- 当日简易流水：今日订单总数、今日营收汇总

> 
> 不包含：会员扣费、复杂营销、支付回调、外卖订单

### 2.3 商家管理后台模块（仅管理员可访问）

#### 2.3.1 菜品管理

- 菜品分类：新增、编辑、删除、排序（上移/下移）
- 菜品维护：新增、编辑、下架、删除；支持按名称/分类关键词搜索
- 菜品属性：名称、图片、售价、所属分类、排序、是否售罄
- 规格组管理：新增规格组、规格选项、选项差价（如大份 +3 元）
- 加料管理：加料名称、加价金额、每单限选数量、绑定菜品

#### 2.3.2 桌台管理

- 桌台区域管理：区域新增、编辑、删除，桌台归属区域
- 桌台新增、编辑、删除
- 批量生成桌台二维码、下载二维码图片；支持单桌二维码查看与复制链接
- 桌台状态可视化：空闲 / 待结算 / 挂单

#### 2.3.3 局域网打印配置（替换云打印）

- 打印机列表管理：添加内网打印机，填写【打印机名称、内网 IP、端口（默认 9100）、用途（后厨小票 / 顾客结账单）】
- 后厨小票 ESC/POS 模板编辑器
- 结账单 ESC/POS 模板编辑器
- 测试打印：向配置 IP:9100 发送测试指令，验证连通性
- 打印日志列表：记录订单 ID、打印机、打印时间、状态、失败原因
- 打印日志筛选：按订单号关键词、单据类型、打印机、状态过滤，带结果计数摘要
- 日志支持操作：查看日志详情（含打印机 IP:端口、失败原因）、手动重打小票（后厨单 / 结账单）、删除日志记录（仅清日志，不动订单）

#### 2.3.4 订单流水查询

- 历史订单筛选：时间段（今日 / 近 7 日 / 自定义区间）、桌号、订单号、结算状态
- 查看订单详情
- 订单流水导出 Excel（对账）

#### 2.3.5 轻量化报表

- 日营收报表：日期、订单数量、总营收
- 菜品销量排行（时间段筛选）
- 退菜记录统计

#### 2.3.6 系统设置

- 门店名称、小票抬头、营业时间（展示在顾客点餐页顶部）配置
- 抹零功能全局开关
- 用户账号管理：新增 / 禁用收银员账号，分配角色（管理员 / 收银员）
- 角色菜单权限配置：按角色配置侧边栏可见菜单（管理员固定全量权限，权限前端过滤 + 接口鉴权双重控制）

#### 2.3.7 操作日志

- 全系统操作留痕：登录、改单、挂单/恢复、退菜、整单取消、结算、手动重打、打印机维护/测试、模板修改、菜品/加料维护、账号维护、角色权限修改、系统设置变更
- 日志字段：时间、操作人、操作类型、操作对象、详情、来源 IP
- 日志筛选：按时间段（今日 / 近 7 日 / 自定义区间）、关键词（对象/详情）、操作类型、操作人过滤，带结果计数
- 日志操作：查看详情弹窗（含日志编号）；支持删除记录（仅管理员、二次确认，提示优先归档；仅清留痕不动业务数据）
- 仅管理员可访问（复用角色菜单权限控制）

## 三、后端服务 api（统一接口服务）

> 
> 部署在店内常开内网主机；可被顾客 web、admin 前端访问；负责 TCP Socket 直连内网打印机 9100 端口发送 ESC/POS

- 用户账号鉴权、Token 签发、接口级角色权限校验（核心安全：收银员不能调用菜品 / 打印机配置接口）
- 菜品、分类、规格、加料 CRUD 接口
- 桌台 CRUD、二维码链接生成接口
- 订单创建接口（顾客提交下单）
- 订单状态流转：`待结算` → `已取消` → `已结清`（最小版不做制作中 / 已上菜状态）
- 订单改单、退菜、整单取消、挂单逻辑
- 局域网打印核心能力
  - 读取后台保存的打印机配置
  - 渲染 ESC/POS 字节流
  - Socket 短连接向 `ip:9100` 发送打印指令
  - 捕获异常，写入打印日志（超时、连接失败等）
- 文件上传：菜品图片存储（内网本地存储）
- 统计聚合接口：营收、销量、退菜统计
- 操作日志：下单、结算、退菜、打印、账号操作日志持久化

## 四、硬件说明 & 配网要点

- 硬件：支持 RAW TCP 9100、ESC/POS 协议的 WiFi / 网口热敏打印机（内网款，不需要云打印固件）
- 配网：打印机接入店内路由器 2.4G WiFi / 网线；路由器绑定静态 IP，防止 IP 变动导致打印失效
- 连通要求：后端主机与打印机在同一局域网网段
- 打印原理：需要打印时临时建立 TCP 短连接发送字节流，发送完成关闭连接；无长连接保活

## 五、完整业务流程

1. 顾客扫桌台二维码打开独立顾客 H5，选菜、填写备注，提交订单
2. 后端生成【待结算】订单，渲染后厨小票 ESC/POS，Socket 连接后厨打印机 IP:9100 打印后厨单
3. 后厨凭纸质小票制作餐品，口头喊桌号上菜，系统不跟踪上菜状态
4. 顾客用餐完毕到前台报桌号 / 订单号结账
5. 收银员打开收银 H5 页面 ，检索订单，核对信息，支持改单、退菜
6. 收银员线下确认收款，点击结算；订单标记【已结清】，自动打印顾客结账单
7. 管理员登录，维护菜品桌台、配置打印机、查看报表与打印日志、重打单据
